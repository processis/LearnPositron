【基础概念】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Beta分布：Beta(α, β)
  • 定义域：θ ∈ [0, 1]（适合概率参数）
  • 形状由两个参数控制：α（alpha）和 β（beta）
  • 都是正数，值越大分布越集中，越小越分散

关键统计量：
  • 平均值：E[θ] = α / (α + β)
  • 众数：Mode[θ] = (α - 1) / (α + β - 2)，当 α > 1 且 β > 1 时有效
  • 方差：Var[θ] = αβ / [(α+β)²(α+β+1)]

【α和β的直观解释】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在Beta-Binomial贝叶斯分析中：
  • α 可理解为：先验中的"成功次数"
  • β 可理解为：先验中的"失败次数"
  • α + β：总的先验信息强度（越大越强）

后验更新规则：
  α_posterior = α_prior + x          （先验成功数 + 观察成功数）
  β_posterior = β_prior + (n - x)    （先验失败数 + 观察失败数）

【α和β值的影响规律】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 当 α = β：对称分布
   └─ α = β = 1：均匀分布（完全无知）
   └─ α = β = 5：对称的钟形分布，中心在0.5

2. 当 α > β：偏右分布（右倾）
   └─ 分布向右偏移，倾向高值（高成功率）
   └─ 众数 > 0.5
   └─ 例：α=8, β=2 → 明显向右偏移，众数≈0.78

3. 当 α < β：偏左分布（左倾）
   └─ 分布向左偏移，倾向低值（低成功率）
   └─ 众数 < 0.5
   └─ 例：α=2, β=8 → 明显向左偏移，众数≈0.22

4. 当 α + β 很大：分布更集中
   └─ 先验信息强：α=100, β=100 → 非常尖锐的中心分布
   └─ 数据影响小：先验权重大

5. 当 α + β 很小：分布更分散
   └─ 先验信息弱：α=0.5, β=0.5 → U形分布
   └─ 数据影响大：先验权重小

6. 当 α < 1 或 β < 1：特殊形状
   └─ α=0.5, β=0.5：U形（两端高，中间低）
   └─ α=0.5, β=1：从0点向上，快速衰减
   └─ α=1, β=0.5：从1点向下，缓慢衰减

【你的数据中的实际例子】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Prior 0.5 (无信息先验)：Beta(1, 1)
  • 平均值 = 0.50（完全中立）
  • 形状：均匀分布（平坦，所有值概率相等）
  • 解释：对成功率一无所知，所以所有概率都有可能
  • 作用：让数据完全驱动结果

Prior 0.75 (有信息先验)：Beta(6, 2)
  • 平均值 = 0.75（偏向高成功率）
  • 众数 ≈ 0.83（高成功率）
  • 形状：明显右倾，集中在高值区域
  • 解释：基于先前经验，我们相信成功率倾向于75%
  • 作用：融入先验知识，影响后验分布

后验更新过程（以实验1为例）：
  ┌──────────────────────────────┐
  │ 原始数据：N=28, x=17          │
  ├──────────────────────────────┤
  │ Prior 0.5 (1, 1)             │
  │   ↓ 贝叶斯更新 ↓              │
  │ 后验 Beta(18, 12)             │
  │ 特征：众数=0.607，平均=0.600  │
  │ 形状：偏右，但不太极端        │
  ├──────────────────────────────┤
  │ Prior 0.75 (6, 2)            │
  │   ↓ 贝叶斯更新 ↓              │
  │ 后验 Beta(23, 13)             │
  │ 特征：众数=0.647，平均=0.639  │
  │ 形状：更偏右，更集中          │
  └──────────────────────────────┘

【参数组合的典型示例】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Beta(1, 1) - 均匀分布
  • 特征：完全平坦，所有值概率相等
  • 平均 = 众数 = 0.50
  • 使用：完全无知的初始状态
  • 在贝叶斯中：无信息先验

Beta(2, 8) - 明显左倾
  • 特征：集中在0-0.4区域，向左倾斜
  • 平均 = 0.20，众数 ≈ 0.11
  • 使用：相信失败率高于成功率
  • 含义：低成功概率

Beta(8, 2) - 明显右倾
  • 特征：集中在0.6-1.0区域，向右倾斜
  • 平均 = 0.80，众数 ≈ 0.78
  • 使用：相信成功率高于失败率
  • 含义：高成功概率

Beta(5, 5) - 对称钟形
  • 特征：中心在0.5，呈钟形，比较集中
  • 平均 = 众数 = 0.50
  • 使用：对0.5有中等强度的信念
  • 含义：50-50的情况，但有信息支持

Beta(3, 3) - 宽阔对称
  • 特征：中心在0.5，但分散度大
  • 平均 = 众数 = 0.50
  • 使用：对0.5有弱信念
  • 含义：倾向中间值，但信息弱

Beta(0.5, 0.5) - U形分布
  • 特征：两端高，中间低，完全倒转
  • 平均 = 0.50，但众数在两端
  • 使用：相信极端值（很低或很高）
  • 含义：两极分化的可能性

Beta(6, 2) - 中等右倾（你的有信息先验）
  • 特征：集中在0.6-1.0，但不如Beta(8,2)极端
  • 平均 = 0.75，众数 ≈ 0.83
  • 使用：中等强度地相信高成功率
  • 含义：经验告诉我们倾向于75%左右

【在你的贝叶斯分析中的应用】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

8个实验的Beta分布特征汇总：

实验1（N=28, x=17, 比例60.7%）
  ├─ Prior 0.5 → Beta(18, 12)：α>β，偏右，众数0.607
  └─ Prior 0.75 → Beta(23, 13)：α>β，更偏右，众数0.647

重复1（N=25, x=19, 比例76%）
  ├─ Prior 0.5 → Beta(20, 7)：α远大于β，明显右倾，众数0.760
  └─ Prior 0.75 → Beta(25, 8)：α更远大于β，更极端右倾，众数0.774

重复2-7的规律：
  ├─ 样本中x > n/2时，后验都是右倾（α > β）
  ├─ α值越大（样本更多），分布越尖锐
  ├─ β值越小（失败越少），分布越向右
  └─ Prior 0.75总是比Prior 0.5更右倾（因为先验已经右倾）

【关键洞察】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 参数的累加作用
   • 贝叶斯更新是累加的：新参数 = 旧参数 + 数据
   • 样本量大时，数据信息量大，先验影响相对减弱
   • 样本量小时，先验影响更显著

2. α和β的相对大小决定偏向
   • α/β的比值决定了向哪边倾斜
   • α=β时完全对称（若α=β>1）
   • α/β越大，越向右偏；越小，越向左偏

3. α+β的绝对大小决定集中度
   • α+β越大，分布越集中（更有信息量）
   • α+β越小，分布越分散（更不确定）
   • 这解释了为什么大样本的信息量大

4. 在你的分析中的体现
   • Prior 0.5：Beta(1,1)是无信息的起点
   • Prior 0.75：Beta(6,2)融入了高成功率的信念
   • 两个先验的差异在于起点不同，但都遵循同样的贝叶斯学习规律

【如何选择先验】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 无信息情形：Beta(1, 1)
   • 完全均匀先验
   • 数据完全驱动结果
   • 适合：真的一无所知

2. 弱信息情形：Beta(2, 2) 或 Beta(3, 3)
   • 对中间值有温和的倾向
   • 但仍给数据很大权重
   • 适合：有一些背景知识但不确定

3. 强信息情形：Beta(10, 5) 或 Beta(20, 10)
   • 参数很大，分布很集中
   • 很强地编码了先前信息
   • 适合：历史数据充分，先验可信

4. 针对性先验：根据具体知识设计
   • 平均值在某处：选择α/(α+β) = 目标值
   • 置信度强弱：通过α+β的大小控制
   • 你的Beta(6,2)：平均值0.75，中等强度

总结：Beta分布的形状完全由α和β两个参数决定。通过调整这两个参数，
你可以编码任何形式的先验信念，从完全无知到极端确定，从左倾到右倾，
从分散到集中。在贝叶斯分析中，这些参数通过与数据的相互作用，
逐步演变为后验分布，体现了"数据更新信念"的过程。
