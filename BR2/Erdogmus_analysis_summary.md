# Erdogmus CMU 重复实验分析报告

## 实验概述

**论文作者**：Erdogmus  
**实验主题**：C语言 vs Python程序性能对比（重复实验）  
**统计方法**：古典假设检验（Z检验）  
**零假设 H₀**：p = 0.5（C程序与Python程序性能无差异）  
**显著性水平**：α = 0.05

## 实验数据与结果

### 表1：CMU实验分析结果

| 试验 | 总数(N) | 快数(x) | x/N | Z值 | p值 | 拒绝H₀ |
|------|--------|--------|-----|-----|-----|--------|
| 实验1 | 28 | 17 | 60.71% | 1.1339 | 0.1284 | No |
| 重复1 | 25 | 19 | 76.00% | 2.6000 | **0.0047** | **Yes** |
| 重复2 | 12 | 8 | 66.67% | 1.1547 | 0.1241 | No |
| 重复3 | 12 | 9 | 75.00% | 1.7321 | **0.0416** | **Yes** |
| 重复4 | 11 | 8 | 72.73% | 1.5076 | 0.0658 | No |
| 重复5 | 10 | 7 | 70.00% | 1.2649 | 0.1030 | No |
| 重复6 | 10 | 8 | 80.00% | 1.8974 | **0.0289** | **Yes** |

**说明**：
- x = C程序快的个数
- N = 总程序对数
- x/N = 样本比例
- Z值 = 标准化统计量，计算公式：Z = (p̂ - 0.5) / √(0.5×0.5/N)
- p值 = 右尾概率（单侧检验），p = P(Z > z_observed)
- 拒绝H₀：当p < 0.05时，拒绝零假设

## 关键发现

### 1. 显著性结果分布

```
总实验次数：8次
├─ 显著的实验（p < 0.05）：3次 (37.5%)
│   └─ 重复1：p = 0.0047 ✓
│   └─ 重复3：p = 0.0416 ✓
│   └─ 重复6：p = 0.0289 ✓
└─ 不显著的实验（p ≥ 0.05）：5次 (62.5%)
    └─ 实验1、重复2、重复4、重复5、重复7
```

### 2. 样本量影响

- **最大样本量**：N = 28（实验1）→ 不显著（p = 0.1284）
- **最小样本量**：N = 5（重复7）→ 不显著（p = 0.0899）
- **平均样本量**：N = 14.1

**观察**：样本量大小与显著性无简单对应关系，样本中C快的比例更重要。

### 3. 效应大小（C快的比例）

| 分组 | 数据 | 显著性 |
|------|------|--------|
| **最高80%** | 重复6, 重复7 | 1显著, 1不显著 |
| **高于75%** | 重复1, 重复3 | 都显著 |
| **低于75%** | 实验1, 重复2, 重复4, 重复5 | 都不显著 |

**规律**：C快的比例 ≥ 75% 时，结合合理的样本量，更容易达到统计显著性。

### 4. Z值与样本量关系

Z值 = (p̂ - 0.5) / √(0.5×0.5/N) = (p̂ - 0.5) × √(N) / 0.5

- **样本量大的好处**：即使比例略高于50%，也可能显著
- **样本量小的困难**：即使比例很高（如80%），显著性仍不确定

## 统计分析细节

### Z检验公式

$$Z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/N}} = \frac{\hat{p} - 0.5}{\sqrt{0.25/N}}$$

其中：
- $\hat{p}$ = x/N（样本比例）
- $p_0$ = 0.5（零假设中的概率）
- N = 总样本数
- SE = √(0.25/N)（标准误）

### p值计算

对于右尾检验：
$$p = P(Z > z_{obs}) = 1 - \Phi(z_{obs})$$

其中 $\Phi$ 是标准正态分布的累积分布函数。

## 结论

### 主要结论

1. **不一致的实验结果**：
   - 即使是同一类型的实验（CMU编程语言对比），重复进行时结果仍不一致
   - 3/8（37.5%）的实验达到统计显著性，5/8（62.5%）不显著

2. **样本比例的重要性**：
   - C程序平均快 **72.64%**
   - 虽然这看起来像是明显优势，但许多情况下无法达到统计显著性
   - 这说明随机波动很大

3. **样本量与显著性的关系**：
   - 样本量（N=5-28）相对较小
   - 较小的样本量会增加随机波动的影响
   - 更大的样本量可能会使结果更稳定

### 实用建议

**对于类似的性能对比实验**：
- 最好进行多次重复实验，不要仅依赖单一结果
- 样本量应至少 N ≥ 20-30
- C快的比例应 ≥ 75% 才能有较高的显著性概率
- 结合效应大小（如点估计）和统计显著性进行判断

## 统计概念解释

### p值的含义

- **p值 = 0.0047** 意味着：如果真实情况是"无差异"（H₀为真），观察到这样或更极端结果的概率仅为0.47%
- 因此我们有充分理由拒绝H₀，认为C程序显著快于Python

### 为什么需要重复实验

1. **验证可重复性**：单次实验可能因随机性而误导
2. **评估一致性**：了解结果的稳定程度
3. **积累证据**：多次实验的综合证据更有说服力

### 统计显著性 vs 实际意义

- **统计显著性**（p < 0.05）：数学上的显著，与样本量和波动有关
- **实际意义**：C快72.64%是否足够大以满足实际需求？
  - 如果性能差异只有5%，统计上显著但实际价值不大
  - 如果差异是2倍以上，则兼具统计和实际意义
