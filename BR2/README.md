# C程序 vs Python程序性能对比实验分析

## 实验概述

**实验设计**
- 样本量：28对对应的Python程序和C程序
- 测试方法：C语言专家用C重写Python程序，对比执行速度
- 实验结果：C程序较快的次数 = 17次（60.71%）

**核心问题**：C程序的这个优势是否具有统计显著性？

## 统计分析结果总结

### 频率主义推断（Z检验）
```
原假设 H₀：p = 0.5（C和Python性能无差异）
对立假设 H₁：p ≠ 0.5

样本比例：p̂ = 0.6071 (60.71%)
标准误：SE = 0.0945
Z统计量：Z = 1.1339
p值（双尾）：p = 0.2568

显著性水平 α = 0.05 时的决策：
✗ 无法拒绝零假设
→ C程序与Python程序的性能无统计显著差异
```

### 贝叶斯推断（Beta-Bernoulli共轭模型）

**先验分布：Beta(8.5, 3.5)**
- 模式（Mode）：0.75（认为C程序有75%概率更快）
- 均值：0.7083
- 95% 置信区间：[0.4349, 0.9165]
- **解释**：事前认为C程序有较强的速度优势

**实验数据**
- 样本量：N = 28
- C程序较快：z = 17次
- 样本比例：0.6071（60.71%）
- 最大似然估计（MLE）：0.6071

**后验分布：Beta(25.5, 14.5)**
- 模式（Mode）：0.6447（融合后认为C程序有64.47%概率更快）
- 均值：0.6375
- 95% 最高密度区间（HDI）：[0.4848, 0.7772]
- 边际似然 p(D)：6.42e-02

**贝叶斯推论**
```
先验期望 → 后验期望
75.0% → 64.5%

可信度变窄（更确定）：
[43.5%, 91.7%] → [48.5%, 77.7%]
宽度：48.2% → 29.3%

→ 数据向下修正了我们对C程序优势的评估
→ 但总体仍认为C程序有64.5%的概率更快
```

## 关键发现与结论

### 1. 统计推论的两个角度

| 方法 | 结论 |
|------|------|
| **频率主义** | Z=1.134, p=0.257 > 0.05 → 无显著差异 |
| **贝叶斯推论** | 后验Mode=0.645，但HDI仍包含0.5 → 不确定 |

### 2. 实验结果的含义

- ✓ **样本数据显示**：C程序在60.71%的案例中更快
- ✗ **但这个优势不够强**：无法达到统计显著性
- ⚠️ **可能的原因**：
  - 样本量不足（N=28较小）
  - 两种语言的性能差异本来就不大
  - 测试条件的随机波动

### 3. 贝叶斯视角的增值

先验信念（C程序75%概率快）遇到数据证据（只有60.71%快）后：
- 后验信念调整到64.47%
- 不确定性大幅下降（HDI变窄）
- 给出了**条件概率**而非单纯的"显著/不显著"判断

### 4. 建议

如果想证实C程序的优势：
1. **增加样本量**：至少100对以上
2. **严格控制条件**：相同的硬件、编译器、优化选项
3. **多次重复**：计算平均值和置信区间
4. **设定实际意义阈值**：定义什么程度的差异才算有实际意义

## 技术细节

### 使用的统计方法

1. **二项检验**（Binomial Test）
   - 使用exact方法计算p值
   - 对小样本量友好

2. **正态近似Z检验**
   - 用于大样本近似
   - 计算标准误和z统计量

3. **Beta-Bernoulli共轭模型**
   - 先验：Beta(α, β)
   - 似然：Bernoulli分布
   - 后验：Beta(α+z, β+n-z)

4. **最高密度区间（HDI）**
   - 更直观的可信区间
   - 使用分位数法计算
