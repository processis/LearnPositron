## 🔑 核心规律速记

### 规律1：比值决定方向
- **α > β** → 分布右倾（向高值倾斜）
- **α < β** → 分布左倾（向低值倾斜）
- **α = β** → 分布对称（中心在0.5）

### 规律2：总和决定集中度
- **α+β越大** → 分布越集中（信息量大）
- **α+β越小** → 分布越分散（信息量小）

### 规律3：贝叶斯更新
- **α_后验 = α_先验 + x**
- **β_后验 = β_先验 + (n-x)**

---

## 💡 数学公式速查

### Beta分布的统计量
```
平均值：E[θ] = α / (α + β)
众数：Mode[θ] = (α - 1) / (α + β - 2)  [当 α>1 且 β>1]
方差：Var[θ] = αβ / [(α+β)²(α+β+1)]
```

### 贝叶斯更新
```
后验 = Beta(α_prior + x, β_prior + (n-x))
```

### 参数解释
```
在Beta-Binomial模型中：
α = 先验成功数 + 观测成功数
β = 先验失败数 + 观测失败数
```

## 📞 快速查询

**问题**: 如何产生左倾分布？
**回答**: 使 α < β，例如 Beta(2, 8)

**问题**: 如何产生更集中的分布？
**回答**: 增加 α+β，例如 Beta(50, 50) 比 Beta(5, 5) 更尖锐

**问题**: 我的数据对应什么参数？
**回答**: 参数 = 先验参数 + 数据(成功数, 失败数)

**问题**: 平均值在哪里？
**回答**: 平均值 = α/(α+β)
